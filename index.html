Application web · PWA · Logiciel Windows

Gestion de Stock

Application de gestion de stock et de caisse pour une boutique, en FCFA. Elle suit les articles, enregistre les sorties et les retours, émet des reçus numérotés et alerte quand un stock devient bas.

  • Deux profils : l’administrateur voit prix d’achat, marges et rapports ; l’employé ne voit que la caisse. Les droits sont appliqués côté serveur.
  • Une sortie baisse le stock et crée le mouvement dans une seule transaction, avec refus si le stock est insuffisant.
  • Installable comme une application, et disponible en exécutable Windows d’un double-clic.

Application web · Temps réel

RestoFlow

Système de gestion de restaurant : le client scanne le QR code de sa table, passe commande, et le personnel suit l’avancement en temps réel.

  • Trois profils : administrateur, serveur, cuisine, avec authentification par jeton (JWT).
  • Mises à jour instantanées des commandes grâce aux WebSockets.
  • Génération de QR codes par table et de reçus PDF, rapports journaliers, mensuels et annuels.

À propos

Des applications pensées pour servir

Je construis des applications web qui répondent à un besoin précis : suivre le stock d’une boutique au Burkina Faso, faire circuler les commandes d’un restaurant, garder le cap sur ses objectifs. Chaque projet part d’un usage réel, puis se transforme en application simple à prendre en main.

  • Les règles au bon endroit. Les droits d’accès et les règles métier sont appliqués côté serveur, pas seulement dans l’interface.
  • Une interface claire. Rapide, lisible, utilisable aussi bien sur ordinateur que sur téléphone.
  • Du code fiable. Testé, documenté, publié avec un historique propre sur GitHub.
